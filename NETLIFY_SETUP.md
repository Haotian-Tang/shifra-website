# Previous Netlify preview

Netlify is no longer the production deployment target. The owner selected **GitHub Pages** for **https://shifra.ae/**. Follow the [GitHub Pages publication and domain instructions](README.md#github-pages-publication).

The former preview project was **shifra-symposium-uae**, at **https://shifra-symposium-uae.netlify.app/**. Its source build configuration and the `shifra.ae` / `www.shifra.ae` custom-domain bindings have been removed. Do not upload new production builds there or point the production domain at Netlify.

The earlier university-hostname proposal, `shifra.mbzuai.ac.ae`, was not activated and is not required for the selected GitHub Pages deployment.

Registration remains hosted by the existing Google Apps Script service, with private Google Sheets and Drive storage. Changing the static website host does not change its intake URL or stored submissions.
